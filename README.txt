PÁGINA DE CUMPLEAÑOS PARA TU NOVIA 💗

ARCHIVOS
- index.html: contenido, carta, imágenes y textos.
- style.css: colores, diseño adaptable a celular y animaciones.
- script.js: botones, sorpresas, corazones y música.
- fotos/: carpeta para guardar fotos personales.

PERSONALIZAR RÁPIDO
1. Abre index.html con el Bloc de notas o un editor de código.
2. Busca "mi niña hermosa" para cambiar el saludo por su nombre o apodo.
3. Edita el texto de la carta para que suene como tú.
4. Para fotos personales, copia tus imágenes dentro de la carpeta fotos y cambia las tres etiquetas <img> para usar, por ejemplo, src="fotos/foto1.jpg".
5. Para música, copia un archivo MP3 llamado musica.mp3 a la carpeta principal. En index.html, busca el comentario que dice "Añade tu archivo de música como musica.mp3" y elimina los comentarios alrededor de la etiqueta <source>, de modo que quede:
   <source src="musica.mp3" type="audio/mpeg">
   Usa una canción que tengas permiso de utilizar. La música empieza cuando ella toque el botón, no automáticamente.

PROBAR EN TU COMPUTADORA
- Haz doble clic en index.html. Se abrirá en tu navegador.
- Para probar las fotos y música, conserva todos los archivos juntos tal como están.

PUBLICAR GRATIS CON GITHUB PAGES
1. Crea una cuenta en https://github.com si no tienes una.
2. Crea un repositorio nuevo, por ejemplo: regalo-cumple.
3. Sube index.html, style.css, script.js, README.txt, la carpeta fotos y musica.mp3 si los usas.
4. En el repositorio, abre Settings → Pages.
5. En "Build and deployment", selecciona "Deploy from a branch".
6. Selecciona la rama "main" y la carpeta "/ (root)", y guarda.
7. Espera unos minutos. GitHub mostrará una dirección parecida a:
   https://TU-USUARIO.github.io/regalo-cumple/
8. Abre el enlace en tu celular para comprobarlo y luego envíaselo a ella.

IMPORTANTE
- GitHub Pages publica el sitio para cualquiera que tenga el enlace o encuentre la dirección. No subas información privada.
- Si las fotos son de ustedes, asegúrate de estar cómodo con que estén publicadas en internet.
- Los enlaces de imágenes de ejemplo necesitan internet; es mejor reemplazarlos por tus propias fotos.
